\# Coaxial TriRotor (Y6) — Nengo Baseline



Baseline dynamics model and control runner for the coaxial tri-rotor (Y6) UAV.



\## Files

\- `y6\_model.py` — Y6 dynamics, parameters/gains, RK4 integrator, baseline controller.

\- `run\_baseline.py` — runs the baseline simulation and plots results.



\## Run

&#x20;   python run\_baseline.py



Requires: numpy, matplotlib.
