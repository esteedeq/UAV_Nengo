# Victor PID R2025a Model Documentation

This folder documents the four R2025a PID conversions:

- `modelo_1gdl_pid_R2025a.md` - corrected 1-DOF hover/altitude controller over `z`.
- `quadri_sub_por_partes_pid_R2025a.md` - separated cascaded PID controller with Victor sigmoid references.
- `quadri_victor_combination_pid_R2025a.md` - combined cascaded PID controller with the same Victor sigmoid mission.
- `quadrotor_model_2020_pid_R2025a.md` - 2020 cascaded PID controller with sinusoidal x/y and piecewise z references.
- `source_truth_map_pid_R2025a.md` - traceability map from source files to corrected generated PID missions.
- `team_meeting_brief_pid_R2025a.md` - short explanation and talking points for sharing the project with the team.

## Corrected Mission Summary

- `Modelo_1gdl_PID_R2025a` controls `z` hover/altitude. It is not a theta controller in this benchmark layer.
- `Quadri_Sub_Por_Partes_PID_R2025a` and `Quadri_Victor_combination_PID_R2025a` use:

```math
z_d=\frac{3}{1+\exp[-(t-4)]},\quad
x_d=\frac{1}{1+\exp[-(t-5)]},\quad
y_d=\frac{1.8}{1+\exp[-(t-5)]},\quad
\psi_d=0
```

- `Quadrotor_model_2020_PID_R2025a` uses:

```math
x_d=y_d=\sin(0.1t)
```

with the source piecewise z schedule.

The models are generated by:

```matlab
build/build_victor_pid_R2025a.m
```

The tunable PID parameters are in:

```matlab
params/victor_pid_params.m
```

The original PD/open-loop models are not modified.
